This project contains the different markdown files for the [Website/Blog of Margitta Kupler](https://margitta-kupler.de/). The original webpage was done in wordpress and the blog is done over the years in one long blogpost. I have written a python script to scrape the content and now there are the different blog-posts one in each markdown file from 2012 until June 2023, which then can be imported into a new webpage/theme.

### Why I built this

My mother has been writing valuable blog content for years, but her WordPress website was running on an outdated theme, and all her blog entries from 2012 to 2023 were stored inside a single, very long post.

I wanted to help her make better use of that content and eventually move to a more modern, mobile-friendly website.

So I wrote a Python scraper to extract the individual entries into separate Markdown files. Since the original formatting wasn't always consistent, this also involved quite a bit of manual cleanup.

I later experimented with rebuilding the site using Hugo and a different theme. The content extraction was completed, but the actual website migration hasn't happened yet.
